# Story timeline

The story timeline has grown into the [plot grid](/guide/plot-grid). Same rows, same cast, same dots: click the **Cast** header on the grid and the cast spreads into one column per name, exactly as the timeline drew it. The command **Open story timeline** is now **Open plot grid** under the same id, so a hotkey bound to it still works, and a timeline left open in a workspace comes back as the grid.
